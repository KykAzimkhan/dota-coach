# Dota Coach в облаке (GitHub Actions)

Каждые 5 минут GitHub сам запускает коуча: он проверяет новые матчи на OpenDota, присылает разбор в Telegram
и отвечает на сообщения боту. Компьютер включать не нужно.

## Настройка (один раз)

1. **Токен Claude.** На компьютере, где есть Claude Code, в терминале выполни:
   `claude setup-token` → войди в аккаунт → скопируй длинный токен.
2. **Секреты в GitHub.** В репозитории: Settings → Secrets and variables → Actions → New repository secret.
   Создай три секрета:
   - `CLAUDE_TOKEN` — токен из шага 1
   - `TELEGRAM_BOT` — токен бота Dota Coach (из BotFather или из config.json на компьютере)
   - `TELEGRAM_CHAT` — твой chat_id (есть в config.json на компьютере)
3. **Проверка.** Вкладка Actions → Dota Coach → Run workflow. Через 1–3 минуты запуск должен стать зелёным.
4. **Выключи коуча на компьютере** (закрой окно и убери ярлык из автозагрузки), иначе будут дубли разборов
   и два коуча будут мешать друг другу читать сообщения в Telegram.

## Что важно знать

- Репозиторий публичный: код, профиль игрока, разборы и `state.json` видны всем. Токены лежат в секретах и не видны.
- Разбор приходит через 5–25 минут после игры, ответ в Telegram — через 0–10 минут
  (GitHub иногда запускает расписание с задержкой).
- Если в репозитории 60 дней нет изменений, GitHub отключает расписание. Коуч сам коммитит состояние
  после каждого матча, так что при регулярной игре этого не случится.
- Изменить профиль игрока — правишь `config.json` прямо на сайте GitHub. Патч — файл `patch_context.md`.
